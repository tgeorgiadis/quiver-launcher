# Quiver Launcher 3.3.4

- Warn when no GitHub token is set. A red banner in the announcement strip explains that unauthenticated GitHub use is rate-limited, so catalog refresh and downloads can fail or stall. Open Settings from the banner to add a token, dismiss it for a week, or hide it permanently. A live announcement still takes priority.
- Improve catalog platform fetching so Windows, Linux, Mac, and Android filters stay accurate. Quiver now loads latest-release assets more efficiently instead of pulling full release lists for every app.
