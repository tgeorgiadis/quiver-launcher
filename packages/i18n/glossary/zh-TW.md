# 繁體中文術語表

使用自然、精簡的臺灣繁體中文。按鈕和標題盡量簡短；語意明確時直接對玩家使用「你」，避免反覆稱呼「玩家」。

| English | 繁體中文 | 說明 |
| --- | --- | --- |
| app | 應用程式 | 遊戲和工具都可稱為應用程式 |
| game | 遊戲 | |
| library | 遊戲庫 | 玩家收藏及已加入的應用程式所在位置 |
| playlist | 播放清單 | 遊戲庫中的自訂清單 |
| Browse | 瀏覽 | 瀏覽目錄的頁面 |
| catalog | 應用程式目錄 | 收錄可瀏覽應用程式的目錄 |
| Add / Install | 新增 / 安裝 | 「新增」是加入遊戲庫；「安裝」是下載並安裝檔案 |
| Play / Play anyway | 遊玩 / 仍要遊玩 | 按鈕文字；不要和「安裝」混用 |
| install / uninstall | 安裝 / 解除安裝 | 動詞 |
| download / Downloads | 下載 / 下載 | 動詞或名詞；頁面名稱也用「下載」 |
| update | 更新 | 依語境作名詞或動詞 |
| release / version | 發行版本 / 版本 | release 指開發者發布的一次建置；version 指其版本號或版本 |
| Change version / Choose a version | 變更版本 / 選擇版本 | |
| downgrade | 降版 | 安裝較舊的版本 |
| pinned (to a version) | 固定版本 | 指不隨更新自動升級 |
| withdrawn (release) | 已撤回 | 發行者或目錄撤回了該版本，不代表玩家已解除安裝 |
| available / not offered / blocked (a release) | 可用 / 暫不提供 / 已封鎖 | Not offered 常指 48 小時等待期間暫不提供；blocked 是已封鎖安裝，依狀態分別使用 |
| preview release | 預覽版本 | |
| pre-release | 預釋出版本 | a release its developer marked as one: an early or experimental build |
| main release | 正式版本 | a release not marked as a pre-release; never "stable" |
| play time / recently played | 遊玩時間 / 最近遊玩 | |
| controller / keyboard | 遊戲控制器 / 鍵盤 | 介面空間有限時可簡稱「控制器」 |
| Settings | 設定 | Quiver Launcher 的全域設定 |
| Setup (an app's mods, launch options, versions) | 應用程式設定 | 單一應用程式的設定頁；與全域「設定」依語境區分 |
| the first start's setup | 初次設定 | 如「設定 Quiver Launcher」、「略過設定」 |
| add (Quiver Launcher 3's apps to the library) | 新增 | 將舊版應用程式加入遊戲庫，檔案仍留在原處 |
| folder / shortcut | 資料夾 / 捷徑 | |
| full screen / theme | 全螢幕 / 佈景主題 | |
| usage data | 使用情況資料 | |
| sign in / sign out / account | 登入 / 登出 / 帳戶 | |
| feedback / player | 意見回饋 / 玩家 | 直接對玩家說話時優先使用「你」 |
| mod | 模組 | |
| launch options / launch flags | 啟動選項 / 啟動參數 | 選項是設定；參數是傳給程式的命令列內容 |
| backup (of the library) | 備份 | |
| GitHub token | GitHub 權杖 | |
| repository | 程式碼儲存庫 | GitHub 或 GitLab 上的專案 |
| card / box art / cover | 卡片 / 封面圖 / 封面 | 卡片是介面項目；box art 是遊戲包裝風格的圖片 |
| grid | 格狀排列 | |
| announcement / dismiss | 公告 / 關閉 | |
| binding (a key or button) | 按鍵對應 | |
| AI / AI-generated | AI / AI 生成 | |
| port (a kind of project) | 移植版 | 指移植到其他平台的遊戲，不是網路連接埠 |
| standalone game | 獨立遊戲 | |
| note (a player's) | 備註 | 玩家為應用程式新增的說明 |
| Note (a README callout) | 注意 | 與玩家留下的「備註」區分 |
| Installed (a version, tab, app, or mod) | 已安裝 | 依語法調整位置，意思不變 |
| Update (a badge or button) | 更新 | 徽章和按鈕依語境理解為「有更新」或「執行更新」 |

產品和平台名稱保留原文：Quiver、Quiver Launcher、GitHub、GitLab、Steam、Steam Deck、Flatpak、AppImage、Thunderstore、GameBanana。主機名稱和控制器按鈕（A、B、LB、RB）也保留原文。
