# 简体中文术语表

用语简洁、自然，面向中国大陆玩家。按钮和标题尽量使用短语；在语境明确时优先用“你”，不必反复使用“玩家”。

| English | 简体中文 | 说明 |
| --- | --- | --- |
| app | 应用 | 不用“程序”；游戏和工具都可称为应用 |
| game | 游戏 | |
| library | 游戏库 | 玩家收藏和已添加应用所在的位置 |
| playlist | 播放列表 | 游戏库中的自定义列表 |
| Browse | 浏览 | 浏览目录的页面 |
| catalog | 应用目录 | 收录可浏览应用的目录 |
| Add / Install | 添加 / 安装 | “添加”加入游戏库；“安装”下载并安装文件 |
| Play / Play anyway | 游玩 / 仍要游玩 | 按钮文案；不要与“安装”混用 |
| install / uninstall | 安装 / 卸载 | 动词 |
| download / Downloads | 下载 / 下载 | 动词或名词；页面名称也用“下载” |
| update | 更新 | 根据语境作名词或动词 |
| release / version | 发布版本 / 版本 | release 指开发者发布的一次构建；version 指其版本号或版本 |
| Change version / Choose a version | 更改版本 / 选择版本 | |
| downgrade | 降级 | 安装较旧版本 |
| pinned (to a version) | 固定版本 | 指不随更新自动升级 |
| withdrawn (release) | 已撤回 | 发布者或目录撤回了该版本，不等于玩家卸载 |
| available / not offered / blocked (a release) | 可用 / 暂不提供 / 已阻止 | Not offered 常指 48 小时等待期间暂不提供；blocked 是已阻止安装，按状态分别使用 |
| preview release | 预览版 | |
| play time / recently played | 游戏时长 / 最近游玩 | |
| controller / keyboard | 手柄 / 键盘 | |
| Settings | 设置 | Quiver Launcher 的全局设置 |
| Setup (an app's mods, launch options, versions) | 应用配置 | 单个应用的配置页面；与全局“设置”区分 |
| the first start's setup | 初始设置 | 如“设置 Quiver Launcher”“跳过设置” |
| add (Quiver Launcher 3's apps to the library) | 添加 | 旧版应用加入游戏库，文件仍留在原处 |
| folder / shortcut | 文件夹 / 快捷方式 | |
| full screen / theme | 全屏 / 主题 | |
| usage data | 使用情况数据 | |
| sign in / sign out / account | 登录 / 退出登录 / 账号 | |
| feedback / player | 反馈 / 玩家 | 直接对玩家说话时优先用“你” |
| mod | 模组 | |
| launch options / launch flags | 启动选项 / 启动参数 | 选项是配置；参数是传给程序的命令行内容 |
| backup (of the library) | 备份 | |
| GitHub token | GitHub 令牌 | |
| repository | 代码仓库 | GitHub 或 GitLab 上的项目 |
| card / box art / cover | 卡片 / 封面图 / 封面 | 卡片是界面项目；box art 是游戏包装风格图片 |
| grid | 网格 | |
| announcement / dismiss | 公告 / 关闭 | |
| binding (a key or button) | 按键绑定 | |
| AI / AI-generated | AI / AI 生成 | |
| port (a kind of project) | 移植版 | 指移植到其他平台的游戏，不是网络端口 |
| standalone game | 独立游戏 | |
| note (a player's) | 备注 | 玩家为应用添加的说明 |
| Note (a README callout) | 注意 | 与玩家留下的“备注”区分 |
| Installed (a version, tab, app, or mod) | 已安装 | 依语法调整位置，含义不变 |
| Update (a badge or button) | 更新 | 徽标和按钮按语境理解为“有更新”或“执行更新” |

产品和平台名称保留原文：Quiver、Quiver Launcher、GitHub、GitLab、Steam、Steam Deck、Flatpak、AppImage、Thunderstore、GameBanana。主机名称和手柄按键（A、B、LB、RB）也保留原文。
